# Puja Birthday Surprise ❤️

A romantic, responsive birthday microsite built with React, Vite, TypeScript, Framer Motion and custom CSS.

## Run locally
1. Install Node.js 20 or later.
2. Open this folder in a terminal.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL printed by Vite.

## Build for deployment
Run `npm run build`. Deploy the generated `dist/` folder to Vercel, Netlify, or any static host.

## Personal media
Your supplied photographs and video are included in `public/memories/`. The site also includes a keepsake collage (`our-story-collage.jpg`) and a short slideshow film (`our-little-movie.mp4`), made locally from the supplied photos and music.

## Background music
The page attempts to autoplay the supplied track at `public/memories/Yedhayya Saami.mp3` as soon as it loads. Some browsers block sound until the visitor interacts with the page; in that case, click **Open your surprise** or the music control to start it. Use the music control to pause or resume it.
